## 5. Ordered implementation steps

1. Copy Sage's three core files into agent/core, renaming imports; replace digest_session with plugins.route_session(), and SYSTEM_PROMPT with plugins.persona().SYSTEM_PROMPT; the guard's retry wording names the persona's product, not DV Digest. Keep every limit and constant.
2. Write agent/routes/dbt_semantic_layer.py: a class whose list_tools() returns the three tools with Sage's input schemas, and whose call_tool() runs GraphQL: metrics for list-metrics and get-dimensions, createQuery then query (polled each 0.5 seconds, 60 seconds at most) for query-metrics, returning rows and labels as Sage's backend does. get-manifest-version returns a clock bucket of 15 minutes, so the core's catalogue cache holds 15 minutes (D-3).
3. Write agent/personas/morgan.py: the instructions (who Morgan is; the data provider, four documents, five checks, two dollar figures, months; every figure from a query; synthetic data) and four suggested questions (D-5).
4. Write agent/deploy.py from Sage's deployment: one function databp-morgan-conversation, its role, its log group, its URL with CORS for https://integrationals.github.io and http://localhost:8000, the three secrets into /databp/morgan from their vault references.
5. Tests: Sage's kept with the route mocked; new ones for the route (GraphQL calls mocked) and the plugins; seen red, then green.
6. Deploy; ask the two probe questions through the function URL; then the page.

Each step states the exact file, object, pattern citation, design or profiling citation, literal first-pass code, expected movement, and any required target rebuild.
